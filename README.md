# Job Portal Application

A full-stack Job Portal web application where users can browse and apply for jobs, while admins can post and manage job listings. This project is built with modern technologies to provide a seamless experience for job seekers and administrators.

## Features

### User Features
- Register and login as a user
- Browse job listings by category or search
- Apply for jobs directly through the portal
- View the list of jobs you have applied for
- User-friendly interface with responsive design

### Admin Features
- Admin login and authentication
- Add new job listings with details
- Edit or delete existing job postings
- View all applications submitted by users
- Manage jobs and applications from an admin dashboard

---

## Tech Stack

- **Frontend:** React, TypeScript, TailwindCSS, Vite  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (or MySQL if you are using it)  
- **Authentication:** JWT for secure login  
- **Version Control:** Git, GitHub
